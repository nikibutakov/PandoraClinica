# MVP перед демо: осознанные упрощения

Дата: 5 ноября 2026. Контекст: показ заказчику 6 ноября, дальше дорабатывает
фронтендщик. Этот документ — что **осознанно не сделано** и почему, чтобы после
демо не гадать, где Debt, а где баг. Статусы задач — в `PLAN.md`.

## Что сделано (кратко)

- `scripts/demo.py` — подъём всего демо-окружения одной командой (+ README «Демо»).
- Рабочие экраны `staff` (заменили заглушки): E7 табло, E1 утро, E3 запись
  и талоны, E5 мой день, E6 приём, E2 пациенты, E4 перезвоны/направления,
  E10/E11 найм-график-слоты, E12 выгрузки. Всё через типизированный клиент
  `@pandora/shared`, ошибки — `formatApiError`, состояния загрузка/пусто/ошибка.

## Осознанно НЕ доделано

### Продуктовые функции

- **Перенос и отмена записи** (E3): бэкенда для отмены нет (`AppointmentStatus`
  есть, эндпоинта нет), на UI не выведено. После демо нужен эндпоинт + кнопки.
- **Статусы «перерыв/закончил» на утреннем экране** (E1): модель `DoctorWorkday`
  хранит `finished_at`, но эндпоинта закрытия смены нет — на UI не выведено.
- **Табло: `in_progress`** — перевода талона «вызван → на приёме» нет в API
  (только call/skip/visit). Табло показывает вызванных; после приёма номер
  исчезает. Ок для демо.
- **Поиск диагнозов по справочнику МКБ-10** (E6): эндпоинта чтения справочника
  диагнозов нет — код и название вводятся вручную, новый код создаётся на бэке.
- **Профили стейкхолдеров** (ЛК пациента, врача и т.п.) — вне MVP.
- **E8 «Персонал» и E9 «Справочники»** — остались заглушками (`Stub.tsx`):
  в демо-сценарии не участвуют, эндпоинты готовы, UI после демо.
- **Деактивация врача** (E10) сделана без расторжения договора (B4 не готов).

### Технический Debt

- **Пагинация** — нигде: демо-объёмы малы, бэк сам ограничивает выдачу
  (пациенты — 50, перезвоны/направления — 200).
- **Опрос вместо push**: табло — 5 сек, «мой день» — 10 сек. WebSocket/SSE —
  после демо.
- **Адаптив/мобильные** — нет (кроме внешнего сайта, он был готов).
- **Обработка ошибок**: на мутациях — `message.error` с русским текстом от бэка;
  отдельных retry-политик нет. На табло при сбое держим последние данные.
- **Часовой пояс**: всё в `Europe/Moscow` (настройка бэка), фронт форматрует
  как есть.
- **dayjs добавлен в зависимости `staff`** — он и так идёт с AntD 5, теперь
  объявлен явно.
- **B3 CORS, B4 расторжение, B5 автоотправка выгрузки, деплой D1–D5** — вне MVP
  (как и договаривались); выгрузка скачивается руками с экрана E12.
- **Скрипт демо** поднимает PostgreSQL через docker compose; если Docker нет, а
  база не запущена — понятная ошибка. Портативный PostgreSQL на машине
  разработчика скрипт подхватывает, если тот уже запущен (проверка коннекта).
- **Безопасность демо**: `admin/admin` и пароли врачей из сида — только для
  показа (B6 — после демо).

## Известные мелочи

- В `E3` прошедшие слоты сегодняшнего дня скрываются на фронте — бэк отдает
  слоты от начала даты.
- `E3` поиск пациента без debounce — на демо-объёме приемлемо.
- `E4` пациент в списке направлений подтягивается из «последних 50 пациентов»:
  если пациента нет в этой выборке, покажется «Пациент №ID».
- `Модалка расписания` (E10) не проверяет пересечения интервалов на клиенте —
  бэк валидирует и вернёт русскую ошибку.
