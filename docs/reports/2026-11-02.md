### Фронтенд — раздел F целиком

- **F1 (PR #4).** Монорепо `frontend/` на npm workspaces: `staff` (:5173),
  `public` (:5174), `shared`. Vite + React + TS, прокси `/api` → бэкенд,
  `npm run dev` поднимает оба приложения.
- **F2 (PR #4).** Типизированный клиент: `npm run gen:api` генерирует типы из
  OpenAPI, схема **закоммичена** — CI и сборка не требуют бэкенда. openapi-fetch:
  Bearer подставляется автоматически, 401 → разлогин (кроме самого логина),
  `formatApiError` выводит сообщения бэка по-русски.
- **F3 (PR #5).** AuthProvider: токен в localStorage, восстановление сессии с
  проверкой срока JWT, guard `RequireRole`, редирект по роли после входа
  (регистратор → утро, врач → мой день, админ → персонал).
- **F4 (PR #5).** AntD Layout: сайдбар с меню по роли, хедер с ФИО и выходом,
  заглушки всех экранов E1–E6, E8–E12 с реальными роутами. Табло E7 — маршрут
  `/board` в `public` (тёмный киоск-режим, без авторизации).
- **F5 (PR #6).** ESLint + Prettier на монорепо, job «Фронтенд (eslint, tsc,
  build)» в CI, добавлен в обязательные проверки. Branch protection теперь
  требует три зелёных job.

## Как поднять окружение

```bash
# 1. PostgreSQL 17 (портативный, если нет docker): из E:\Pandora\.tools
"E:\Pandora\.tools\pgsql\bin\pg_ctl.exe" -D "E:\Pandora\.tools\pgdata" -o "-p 5432" -l "E:\Pandora\.tools\pg.log" start

# 2. Бэкенд (миграции уже накатены, база pandora_clinic с демо-данными)
cd backend && ../.venv/Scripts/uvicorn.exe app.main:app --port 8000

# 3. Фронты
cd frontend && npm run dev   # staff :5173, public :5174
```

Учётки демо: `admin/admin`, `registrar/registrar`, врачи — пароль `doctor`.
Swagger: http://localhost:8000/docs
