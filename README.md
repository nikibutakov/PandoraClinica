# PandoraClinica

Система поликлиники: поток пациентов через регистратуру, график врачей и слоты
записи, живая очередь с талонами и табло, направления между врачами, вечерняя
выгрузка приёмов раздельно по гражданству.

## Стек

- **БД** — PostgreSQL 17 (docker compose для разработки)
- **Бекенд** — FastAPI, один сервис: SQLAlchemy 2.x, Alembic, JWT + роли, pytest
- **Фронтенд** — React, два приложения (внутреннее для персонала и внешнее для
  пациентов); пока не начаты

## Структура

```
backend/
  app/
    main.py        # FastAPI: роутеры, группы Swagger, /healthz
    config.py      # настройки из переменных окружения
    database.py    # engine и сессии БД
    models.py      # SQLAlchemy-модели (16 таблиц)
    schemas.py     # Pydantic-схемы запросов и ответов
    security.py    # bcrypt-пароли, JWT, проверка ролей
    seed.py        # создание первого администратора
    routers/       # auth, public, board, registrar, doctor, admin
  migrations/      # Alembic-миграции
  tests/           # pytest: сквозной цикл пациента + все блоки API
docker-compose.yml # PostgreSQL для локальной разработки
```

## Быстрый старт

```bash
# 1. База: PostgreSQL 17 на localhost:5432 (pandora/pandora, база pandora_clinic)
docker compose up -d

# 2. Окружение
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 3. Схема БД (миграции)
alembic upgrade head

# 4. Первый администратор; по умолчанию admin/admin — смените пароль после входа
python -m app.seed              # или: python -m app.seed <логин> <пароль>

# 5. Сервер разработки
uvicorn app.main:app --reload   # http://localhost:8000
```

Swagger UI — **http://localhost:8000/docs** (редирект с корня). Войдите через
`POST /api/auth/login`, вставьте токен в кнопку **Authorize** — и все закрытые
блоки можно тестировать прямо из браузера.

## Тесты

Тесты создают отдельную базу `pandora_clinic_test` на localhost:5432 —
нужен запущенный `docker compose up -d`:

```bash
cd backend && pytest            # полный набор
pytest tests/test_full_cycle.py # сквозной цикл заявки пациента
```

## Миграции

```bash
alembic upgrade head                        # применить все
alembic revision --autogenerate -m "суть"   # новая миграция по изменению models.py
```

## Конфигурация

Переопределяется переменными окружения (или `.env` в `backend/`):

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DATABASE_URL` | `postgresql+psycopg2://pandora:pandora@localhost:5432/pandora_clinic` | подключение к БД |
| `SECRET_KEY` | dev-значение | секрет JWT; в проде обязательно переопределить |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | `480` | срок жизни токена (рабочая смена) |
| `SLOT_MINUTES` | `30` | длина слота при генерации из графика |
| `CLINIC_TIMEZONE` | `Europe/Moscow` | часовой пояс «сегодня» и табло |

## API за минуту

Роли: `admin` (администратор), `registrar` (регистратура), `doctor` (врач).
Блоки «Внешний сайт» и «Табло» публичные, остальные — по JWT.

| Группа в Swagger | Доступ | Что внутри |
|---|---|---|
| Внешний сайт | без входа | свободные слоты по специальности, специальности, заявка на перезвон |
| Табло | без входа | очередь для ТВ: кабинеты, кто принимает, вызванные номера, ожидание |
| Регистратура (4 группы) | registrar, admin | утренний экран и кабинеты; пациенты; запись и талоны; направления и перезвоны |
| Врач (2 группы) | doctor | смена и очередь (вызов, «не дождался»); приём с диагнозами МКБ-10 и направления |
| Администратор (5 групп) | admin | персонал; справочники; найм врачей и график; генерация слотов; вечерняя выгрузка РФ/не-РФ |

Типовой день в API: админ генерирует слоты → регистратор утром закрепляет
врачей за кабинетами и записывает пациентов → визит: талон → врач вызывает и
принимает → при необходимости направление к специальности → вечером админ
забирает выгрузку `GET /api/admin/reports/daily?date=...`.
